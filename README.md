# Console Rock, Paper, Scissors Game

An interactive, terminal-based implementation of the classic Rock, Paper, Scissors game built using Python. This program tracks scores across multiple rounds, validates user selections, and lets you play for as long as you want.

## 🚀 Features

* **Interactive Gameplay:** Play against a computer opponent utilizing randomized decision mechanics.
* **Score Tracking:** Keeps an ongoing tally of the player's and computer's scores across multiple rounds.
* **Typo Protection:** Automatically converts inputs to lowercase and trims whitespace to avoid accidental input errors.
* **Flexible Exit:** Type `exit` during any weapon selection phase or answer `n` at the round end prompt to quit cleanly.

---

## 🛠️ Requirements

* **Python 3.x** installed on your operating system.
* No external libraries or installations required (uses Python's native `random` module).
